About this experiment

Loading parameter count… shared across English, Mandarin, Spanish, French and German. The voice model is trained from scratch on existing recordings. A fixed audio synthesizer turns its predictions into sound.

Model weights and supporting assets are measured separately.

Pronunciation uses MFA dictionaries with stress annotations prepared using eSpeak NG. Unknown dictionary words currently produce an error. Text stays on this device; there is no speech server.
